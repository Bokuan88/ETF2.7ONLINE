📁 本機資料庫資料夾（持股＋股價共用，記住舊資料，換電腦也能帶著走）

線上版已會自動從 GitHub 的 holdings/ 與 prices/ 載入，通常無需再操作。若要在本機額外累積資料，仍可連接一個資料夾（建議跟這個 HTML 放同一層）。本機資料夾裡會自動建立 holdings/（每個帳戶一個檔案）跟 prices/（每檔股票一個檔案）兩個子資料夾——不是全部資料擠在一個檔案裡，之後新增資料只會重寫「真正有變動」的那一個帳戶／股票檔案，不會動到其他資料，也不會有單一檔案無限長大、越存越慢的問題。
同一個帳戶只會新增資料庫裡還沒有的日期，既有日期永遠不會被覆蓋或刪除。下次打開網頁會自動嘗試重新連接，不用每次都重新上傳所有 Excel 原始檔。搬到別台電腦時，把 HTML 和整個資料夾一起複製過去，在那台電腦點一次「選擇／建立資料庫資料夾」即可繼續累積。
提醒：在畫面上按「移除」某個帳戶或「清空全部」，只是暫時從畫面隱藏，不會刪除資料夾裡的檔案。
⚠️ 你目前使用的瀏覽器不支援這個功能（只有電腦版 Chrome／Edge 支援），資料只會保留在這次瀏覽中；建議改用 Chrome／Edge，或用「匯出快照／載入快照」手動搬移。

線上版如何永久保存新上傳的 Excel？

網頁無法直接改寫 GitHub 上的檔案。上傳 Excel 後若要下次開啟仍看得到： 按右上角「匯出 GitHub 資料包」→ 下載 zip → 解壓後把裡面的 holdings/、prices/ 覆蓋上傳到 GitHub → push 完成。 （「匯出快照」則是單一備份檔，下次用「載入快照」還原，不會更新 GitHub 上的分檔 JSON。）

這個工具如何處理「日期沒對齊」與「資料中斷」

・每個帳戶只用自己實際存在的日期工作表畫線，不會用「最接近的日期」去湊資料，所以增減、成本計算都是帳戶自己的真實數字。
・跨帳戶比較時，圖表 X 軸改用真實日曆日期對齊（不是用第幾張表），所以不同帳戶只要日期相同就會疊在同一個縱線上。
・某帳戶在某天沒有資料，就是「留白」，不會被當成 0 股或用其他天的數字頂替，避免中斷被誤讀成出脫或沒有意義的斷點。

方法一（推薦）：直接上傳你的「多檔比較」價格報表

支援你原本 Excel VBA 產生的那種報表格式——每個股票一個工作表，欄位以「日期／股數／收盤價／買入金額」為一組、並排列出各帳戶的資料（就像你附的 2303_PRICE.xlsx 那樣）。 系統會自動掃描檔案裡每一組「收盤價」欄位，把日期與收盤價全部整理進資料庫；股票代碼會從工作表名稱（例如「2303聯電_多檔比較」）或第一列標題自動判斷。可以一次選多個檔案。

📄
拖曳「多檔比較」價格報表到這裡，或點擊選擇（.xlsx／.xls／.xlsm，可多選）

方法二：嘗試線上抓取（不保證成功）

瀏覽器基於安全機制（CORS），大部分情況下無法直接向 Yahoo Finance 這類網站要資料——這是瀏覽器本身的限制，不是這個工具的臭蟲。工具會自動多方嘗試（直接連線＋兩個公開轉接服務），成功與否會依你當下的網路環境而定；抓不到時，請改用方法一或方法三。
